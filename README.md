# Toko Bunga Hias 💐

Sebuah program toko bunga berbasis Python dengan dua peran utama: **Admin** dan **Pelanggan**. Sistem ini memudahkan pengelolaan toko, transaksi, dan promosi.  

---

## Fitur Utama

### Pelanggan
- Registrasi dan login akun.
- Lihat menu bunga (nama, harga, stok, warna).
- Belanja dengan keranjang.
- Tukar poin untuk diskon:
  - 500 poin → 30%
  - 1000 poin → 40%
  - 2000 poin → 50%
- Lihat promo hari ini.
- Lihat riwayat belanja.
- Lihat poin.
- Cetak struk pembelian (`.txt`) secara otomatis.

### Admin
- Login admin khusus.
- Tambah bunga baru.
- Edit bunga (nama, harga, stok, warna).
- Hapus bunga.
- Daftarkan admin baru.
- Lihat info toko:
  - Jumlah admin
  - Pengunjung hari ini
  - Total nilai stok bunga
  - Total transaksi hari ini
